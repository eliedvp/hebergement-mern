# MERN App - Déploiement sur Azure

Cette application est un projet MERN (MongoDB, Express, React, Node.js) complet qui récupère et affiche des tâches depuis une base de données MongoDB Atlas. Elle est prête à être déployée sur Microsoft Azure.

---

## 🚀 Fonctionnalités

- Frontend React affichant les tâches de MongoDB Atlas
- Backend Node.js/Express avec API REST `/api/lists`
- Connexion sécurisée à MongoDB Atlas via `MONGO_URI`
- Serve le frontend compilé (`build`) depuis Express
- Prêt pour déploiement sur Azure App Service
